# W Beauty Studio — Website

React + Vite + Tailwind CSS site.

## Run locally

Requires Node.js 22.12+ (or 20.19+).

```bash
npm install
npm run dev
```

Then open the URL it prints (usually http://localhost:5173).

## Build

```bash
npm run build
```

Produces a single self-contained `dist/index.html` (images are served from `public/images/`, copied into `dist/`).
